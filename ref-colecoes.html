Java Cola de Coleções

Uma página para consultar quando você precisar escolher uma coleção ou lembrar o nome de um método. Primeiro a tabela "qual usar", depois os métodos de List, Set, Map e Deque, com exemplos e resultados reais do JShell. Para aprender cada uma com calma, comece pela Visão Geral das Coleções.

Nesta página
  • Interfaces × implementações: ordem, duplicados, null e velocidade.
  • A mesma lista em cada coleção, para ver as diferenças.
  • Métodos de List, Set, Map e Deque.
  • Coleções imutáveis (List.of, Map.of) e os erros mais comuns.

Todos os exemplos começam com import java.util.*. Na hora de declarar, use a interface à esquerda e a implementação à direita: List<String> nomes = new ArrayList<>();. Assim, trocar de implementação depois é mudar uma palavra.

Na dúvida

Lista: ArrayList. Sem repetidos: HashSet. Chave → valor: HashMap. Precisa de ordem? Troque por TreeSet/TreeMap (ordenado) ou LinkedHashSet/LinkedHashMap (ordem de inserção). Pilha ou fila: ArrayDeque.

A mesma lista em cada coleção

Cinco frutas, com maçã repetida, copiadas para cada tipo de coleção:

$ jshell
|  Welcome to JShell -- Version 25.0.4.1
|  For an introduction type: /help intro

jshell> import java.util.*

jshell> var frutas = List.of("uva", "maçã", "banana", "kiwi", "maçã")
frutas ==> [uva, maçã, banana, kiwi, maçã]

jshell> new ArrayList<>(frutas)
$3 ==> [uva, maçã, banana, kiwi, maçã]

jshell> new LinkedList<>(frutas)
$4 ==> [uva, maçã, banana, kiwi, maçã]

jshell> new HashSet<>(frutas)
$5 ==> [banana, uva, kiwi, maçã]

jshell> new LinkedHashSet<>(frutas)
$6 ==> [uva, maçã, banana, kiwi]

jshell> new TreeSet<>(frutas)
$7 ==> [banana, kiwi, maçã, uva]

As listas guardam tudo, na ordem. Os conjuntos tiram a maçã repetida: o HashSet numa ordem própria (que pode mudar de uma versão do Java para outra), o LinkedHashSet na ordem de chegada e o TreeSet em ordem alfabética.

Experimente: elimine os repetidos e ordene ao mesmo tempo: crie um TreeSet a partir de List.of(5, 3, 8, 3, 1, 5).

new java.util.TreeSet<>(java.util.List.of(5, 3, 8, 3, 1, 5))

Pares de métodos: exceção ou valor especial

Cada operação de fila existe em duas versões: uma lança exceção quando não dá (add, remove, element, pop) e outra devolve false/null (offer, poll, peek). Para filas que podem ficar vazias, prefira a segunda e confira o null.

Coleções imutáveis

List.of(…), Set.of(…) e Map.of(…) Java 9+ criam coleções prontas que não podem ser alteradas. Ótimas para dados fixos; para uma lista que vai mudar, copie: new ArrayList<>(List.of(…)). stream().toList() Java 16+ também devolve uma lista imutável.

FormaPode mudar?Aceita null?
new ArrayList<>(), new HashMap<>()…simsim (exceto Tree… e ArrayDeque)
List.of, Set.of, Map.of, stream().toList()nãonão
Arrays.asList(array)pode trocar itens (set), não pode mudar o tamanhosim

Resumo

  • List = sequência com posições e repetidos; Set = sem repetidos; Map = chave → valor; Deque = pilha e fila.
  • Hash…: rápido, sem ordem; Linked…: ordem de inserção; Tree…: ordenado, O(log n), sem null.
  • Padrões: ArrayList, HashSet, HashMap, ArrayDeque. Declare pela interface.
  • List.of/Set.of/Map.of são imutáveis e recusam null.
