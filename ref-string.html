Java Métodos de String

Todos os métodos de String que você vai usar no dia a dia, agrupados pelo que fazem. Cada linha tem a assinatura, uma explicação curta, um exemplo e o resultado real, conferido no JShell do JDK 25. Para aprender com calma, veja as aulas Strings e Métodos de String.

Como ler as tabelas
  • A assinatura começa pelo tipo do resultado: int length() devolve um int; String substring(…) devolve uma String.
  • Os resultados estão no formato do JShell: textos entre aspas duplas ("nana"), caracteres entre aspas simples ('A') e arrays como String[3] { "a", "b", "c" }.
  • Os índices começam em 0: em "banana", o b é a posição 0 e o último a é a 5.
  • Nenhum método muda o texto original: String é imutável. Todos devolvem um valor novo (veja abaixo).

Armadilhas

Esquecer que String é imutável 
        String nome = "Ana";
        nome.toUpperCase();
        System.out.println(nome);
        nome = nome.toUpperCase();
        System.out.println(nome);

$ java Main.java
Ana
ANA

A primeira chamada calculou "ANA" e jogou fora: nome continuou "Ana". Para guardar o resultado, atribua: nome = nome.toUpperCase();. Vale para todos os métodos desta página.

Comparar com == 
        String a = "Ana";
        String b = new Scanner("Ana").next();
        System.out.println(a == b);
        System.out.println(a.equals(b));

$ java Main.java
false
true

O texto é o mesmo, mas o que veio do Scanner é outro objeto. O == compara se são o mesmo objeto; o equals compara o conteúdo. Com textos digitados, lidos de arquivo ou montados no programa, o == dá false. Use sempre equals (veja Strings).

Missão: separe o e-mail em usuário e domínio usando indexOf('@') e substring (sem split), mostrando Usuário: ana.souza e Domínio: exemplo.com. O e-mail tem espaços sobrando e uma letra maiúscula: limpe com strip() e toLowerCase() antes.

public class Main {
    public static void main(String[] args) {
        String email = "  Ana.Souza@exemplo.com ";
        // limpe o e-mail, ache a posição do @ e separe as duas partes
    }
}

public class Main {
    public static void main(String[] args) {
        String email = "  Ana.Souza@exemplo.com ";
        email = email.strip().toLowerCase();
        int arroba = email.indexOf('@');
        String usuario = email.substring(0, arroba);
        String dominio = email.substring(arroba + 1);
        System.out.println("Usuário: " + usuario);
        System.out.println("Domínio: " + dominio);
    }
}

Resumo

  • Tamanho e posições: length, charAt, indexOf/lastIndexOf (−1 se não achar), substring(início, fim) sem o fim.
  • Testes: isEmpty, isBlank, contains, startsWith, endsWith, equals, equalsIgnoreCase, compareTo.
  • Transformações: toUpperCase, strip, replace, repeat, split (regex!), String.join, String.format (vírgula em pt_BR).
  • Nenhum método altera a String: guarde o resultado. Compare com equals, nunca com ==.
