Nível 1 · Iniciante

1. O que este código imprime?

System.out.println(10 / 3);
Explicação

Entre dois int, a divisão é inteira: a parte decimal é descartada (não arredonda).

Revise: Operadores Aritméticos

2. O que este código imprime?

System.out.println(10 % 3);
Explicação

% é o resto da divisão: 10 = 3 × 3 + 1.

Revise: Operadores Aritméticos

3. O que este código imprime?

System.out.println(1 + 2 + "3" + 4 + 5);
Explicação

Da esquerda para a direita: 1 + 2 = 3 (números); 3 + "3" = "33" (vira texto); daí em diante tudo é concatenação: "3345".

Revise: Concatenação

4. O que este código imprime?

int x = 5;
x += 3 * 2;
System.out.println(x);
Explicação

x += 3 * 2 é x = x + (3 * 2): a multiplicação vem primeiro. 5 + 6 = 11.

Revise: Operadores de Atribuição

5. O que este código imprime?

char c = 'A';
c++;
System.out.println(c);
Explicação

Um char é um número (o código Unicode). 'A' é 65; mais 1 dá 66, que é 'B'. Como a variável é char, imprime a letra.

Revise: char e boolean

6. O que este código imprime?

System.out.println(0.1 + 0.2);
Explicação

O double guarda os números em binário, e 0,1 e 0,2 não têm representação exata. Para dinheiro, use BigDecimal.

Revise: double e float

7. O que este código imprime?

int i = Integer.MAX_VALUE;
i++;
System.out.println(i);
Explicação

Overflow: passar do maior int "dá a volta" para o menor, sem erro nenhum.

Revise: int, long, short, byte

8. O que este código imprime?

for (int i = 0; i < 3; i++) {
    System.out.print(i + " ");
}
Explicação

Começa em 0 e repete enquanto i < 3: 0, 1 e 2.

Revise: for

9. O que este código imprime?

String s = "Java";
System.out.println(s.length() + s.charAt(0));
Explicação

Pegadinha: length() é int e charAt(0) é char. int + char é uma conta: 4 + 74 (o código de 'J') = 78. Para juntar como texto, comece com uma String: "" + 4 + 'J'.

Revise: char e boolean

10. O que este código imprime?

int dia = 7;
String t = switch (dia) {
    case 1, 7 -> "fim de semana";
    default -> "dia útil";
};
System.out.println(t);
Explicação

case 1, 7 junta dois valores. Com setas, não existe "cair" no próximo caso, então não precisa de break.

Revise: switch com Setas

11. Quanto vale b?

boolean b = 5 > 3 && 2 > 4 || true;
Explicação

&& é feito antes de ||: (true && false) || true = false || true = true.

Revise: Precedência

12. O que este código imprime?

double d = 7 / 2;
System.out.println(d);
Explicação

7 / 2 é calculado entre dois int (dá 3) antes de ir para o double, que só acrescenta o .0. Para 3.5: 7.0 / 2.

Revise: Conversão de Tipos

13. Na máquina da Ana (sistema em português do Brasil), o que isto imprime?

System.out.printf("%.2f%n", 3.14159);
Explicação

printf e String.format usam o idioma do sistema: em pt_BR, vírgula decimal. Já o println de um double sempre usa ponto.

14. O que este código imprime?

int[] v = {4, 8, 15};

for (int x : v) soma += x;

20. O que este código imprime?

21. O que imprime depois de três new Contador()?

class Contador {

new Contador(); new Contador(); new Contador();

Explicação

Um atributo static é um só para a classe inteira: os três objetos somam no mesmo total.

Revise: static

22. O que este código imprime?

try {
    System.out.println("A");
    int x = 1 / 0;
    System.out.println("B");
} catch (ArithmeticException e) {
    System.out.println("C");
} finally {
    System.out.println("D");
}
Explicação

A divisão por zero pula o resto do try (o B não aparece), vai para o catch e, no fim, o finally roda sempre.

Revise: finally

26. O que imprime?

StringBuilder sb = new StringBuilder("abc");

Ao contrário da String, o StringBuilder muda: reverse inverte o próprio texto e append acrescenta no fim.

27. O que imprime?

Integer a = 127, b = 127;
System.out.println(a == b);
Integer c = 128, d = 128;

Explicação

O Java reaproveita os objetos Integer de -128 a 127, então a e b são o mesmo objeto; 128 cria objetos diferentes. Moral: compare wrappers com equals.

28. O que new B() imprime?

Todo construtor começa chamando o da mãe (um super() invisível). Primeiro roda o de A, depois o de B.

Revise: super

29. Quanto vale fat(5)?

Recursão com caso base (n <= 1): 5 × 4 × 3 × 2 × 1 = 120.

Revise: Recursão

43. O que descreve(new Circulo(20)) devolve?

sealed interface Forma permits Circulo, Quadrado { }
record Circulo(double r) implements Forma { }
record Quadrado(double l) implements Forma { }

static String descreve(Forma f) {
    return switch (f) {
        case Circulo c when c.r() > 10 -> "círculo grande";
        case Circulo c -> "círculo";
        case Quadrado q -> "quadrado " + q.l();
    };
}
Explicação

O primeiro case que casa ganha; a guarda when exige raio maior que 10. E não precisa de default: a interface é selada, e o compilador sabe que os dois tipos foram cobertos.

Revise: Pattern Matching

44. Como fica a lista depois deste sort?

List<String> l = new ArrayList<>(List.of("kiwi", "uva", "banana", "caju"));
l.sort(Comparator.comparing(String::length)
        .thenComparing(Comparator.naturalOrder()));
Explicação

Primeiro pelo tamanho (uva tem 3, caju e kiwi têm 4, banana 6); no empate, ordem alfabética: caju antes de kiwi.

Revise: Comparable e Comparator
