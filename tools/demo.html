Página de teste (fora do menu) com os componentes .tryjava e .tryjshell.

1. Missão simples

Missão: troque "mundo" por "Ana" e clique em Rodar.

public class Main {
    public static void main(String[] args) {
        System.out.println("Olá, mundo!");
    }
}

public class Main {
    public static void main(String[] args) {
        System.out.println("Olá, Ana!");
    }
}

2. Entrada pelo teclado (campo na própria saída)

Rode e digite o nome e a idade quando o programa pedir.

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Nome: ");
        String nome = sc.nextLine();
        System.out.print("Idade: ");
        int idade = sc.nextInt();
        System.out.printf("%s terá %d anos em 2027.%n", nome, idade + 1);
    }
}

4. Exceção e código de saída

Missão: divida por zero.

public class Main {
    static int dividir(int a, int b) {
        return a / b;
    }
    public static void main(String[] args) {
        System.out.println(dividir(10, 2));
    }
}

public class Main {
    static int dividir(int a, int b) {
        return a / b;
    }
    public static void main(String[] args) {
        System.out.println(dividir(10, 0));
    }
}

5. Vários arquivos (abas) e argumentos

public class Main {
    public static void main(String[] args) {
        Pessoa p = new Pessoa(args[0], Integer.parseInt(args[1]));
        System.out.println(p.apresentar());
    }
}

public class Pessoa {
    private final String nome;
    private final int idade;

    public Pessoa(String nome, int idade) {
        this.nome = nome;
        this.idade = idade;
    }

    public String apresentar() {
        return nome + " tem " + idade + " anos";
    }
}

6. Laço infinito (o simulador para sozinho)

public class Main {
    public static void main(String[] args) {
        int i = 0;
        while (true) {
            i++;
        }
    }
}
