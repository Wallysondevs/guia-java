Java Projetos

Nas aulas, cada página ensina um assunto. Nos projetos, você junta vários assuntos para construir um programa de verdade, do arquivo vazio até a versão final. É aqui que o que você estudou "encaixa": o Scanner da aula de entrada conversa com o switch, que chama um método, que lança uma exceção que você mesmo criou.

Você vai aprender
  • Como os seis projetos do guia estão organizados (em etapas pequenas).
  • Que aulas cada projeto pratica e em que ordem fazê-los.
  • Como rodar cada etapa: no editor do guia ou no terminal do seu computador.
  • O que fazer quando o seu código não bate com o da etapa.

A ideia: construir como um pedreiro, não como um mágico

Ninguém escreve um programa inteiro de uma vez. Um pedreiro não levanta a casa num dia: primeiro a fundação, depois uma parede, confere se está no prumo, depois a outra. Programar é igual. Cada projeto deste guia é dividido em etapas, e cada etapa acrescenta uma coisa nova ao programa da etapa anterior. No fim de toda etapa, o programa compila e roda. Você nunca fica com um monte de código "que ainda não funciona".

Toda página de projeto segue o mesmo roteiro:

  1. O que vamos construir. Uma sessão real do programa pronto, para você ver aonde vai chegar.
  2. Antes de começar. As aulas que você precisa ter visto (com links) e a pasta onde o projeto vai morar.
  3. As etapas. Cada uma mostra o código novo, explica linha a linha o que mudou, mostra a saída real (rodada num JDK 25 de verdade) e termina com uma caixa Experimente em que você faz a etapa.
  4. Quando dá errado. Os erros que aparecem de verdade nesse projeto, com a mensagem completa e a correção.
  5. O código completo e os desafios. A versão final, inteira, e ideias para você continuar sozinho.

Onde rodar: duas formas

1. No editor do guia (mais fácil)

Toda etapa tem uma caixa Experimente com o código da etapa anterior. Você edita, clica em Rodar e vê a saída. Quando o programa lê o teclado, aparece um campo para você digitar (ou o guia já preenche a entrada da missão). Se travar, o botão de solução mostra a resposta. Veja como o editor funciona em O Editor do Guia.

Experimente agora. Este é o "esqueleto" de todo projeto do guia: uma classe com o método main que mostra o título do programa.

Missão: troque o título para === Meu Primeiro Projeto === e clique em Rodar.

public class Main {
    public static void main(String[] args) {
        System.out.println("=== Título ===");
    }
}

public class Main {
    public static void main(String[] args) {
        System.out.println("=== Meu Primeiro Projeto ===");
    }
}

2. No terminal do seu computador (o jeito "de verdade")

Para guardar o seu trabalho, crie uma pasta para cada projeto dentro de ~/java e escreva o arquivo num editor (Editores e IDEs mostra as opções). Depois rode com java NomeDoArquivo.java. Esta é a máquina da Ana fazendo a primeira etapa da calculadora:

$ mkdir -p java/calculadora        « cria a pasta do projeto (e a java, se não existir)
$ cd java/calculadora
$ ls
Calculadora.java                   « o arquivo que a Ana escreveu no editor
$ java Calculadora.java
=== Calculadora da Ana ===
Primeiro número: 10                « 10 e 5 foram digitados pela Ana
Segundo número: 5
10.0 + 5.0 = 15.0

O comando java Calculadora.java (com o .java no fim) compila o arquivo na memória e já executa, sem deixar arquivos .class na pasta. É o jeito mais rápido para projetos de um arquivo. A outra forma, em dois passos, é a que você aprendeu em javac e java:

$ javac Calculadora.java           « compila: gera o Calculadora.class
$ ls
Calculadora.class  Calculadora.java
$ java Calculadora                 « executa a classe (sem .java no fim)
=== Calculadora da Ana ===
Primeiro número: 7
Segundo número: 3
7.0 + 3.0 = 10.0

Os projetos com vários arquivos (agenda, biblioteca) também rodam com java Principal.java: desde o Java 22, o lançador encontra sozinho as outras classes na mesma pasta. Os dois últimos projetos (banco e tarefas) usam o Maven, e a página explica cada comando.

Como estudar um projeto

  1. Leia a etapa inteira antes de digitar. Entenda o que muda e por quê.
  2. Digite o código, não copie e cole. Parece mais lento, mas é digitando que você erra, lê a mensagem do javac e aprende a consertar. Os erros mais comuns estão em Erros do Compilador.
  3. Rode depois de cada etapa e compare com a saída mostrada. Se for diferente, procure a diferença no código antes de seguir.
  4. Mude alguma coisa. Troque uma mensagem, um número, uma condição. Rode de novo. Prever o que vai acontecer e conferir é o melhor exercício que existe.
  5. Só então vá para a próxima etapa.
"O meu não funciona e o da página funciona"

Quase sempre é um destes: uma letra maiúscula diferente (string em vez de String), um ; esquecido, uma chave } a mais ou a menos, ou o nome do arquivo diferente do nome da classe pública. Leia a primeira linha do erro: ela diz o arquivo e o número da linha (Calculadora.java:9: error: …). Veja como ler essas mensagens em Lendo Erros do javac e, se aparecer uma exceção na hora de rodar, em Exceções Comuns.
