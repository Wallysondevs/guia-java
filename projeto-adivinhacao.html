Projeto Jogo da Adivinhação

O computador pensa num número e você tenta adivinhar. A cada palpite, ele diz se o número secreto é maior ou menor. É o jogo clássico de quem aprende a programar, porque usa um pouco de tudo: sorteio, repetição, decisões, contagem e, na versão final, níveis de dificuldade feitos com enum e um recorde.

Você vai praticar
  • Sortear números com Random.
  • Decidir com if, else if, else e repetir com while e do-while.
  • Contar tentativas e usar constantes (final).
  • Validar números inteiros com hasNextInt.
  • Criar um enum com atributos e construtor.
  • Guardar o melhor resultado (recorde) entre partidas.

Como o número é sorteado, cada vez que você rodar o jogo vai ver números diferentes. As etapas:

  1. Sortear e dar um palpite (Random, if/else).
  2. Repetir até acertar (while, contador).
  3. Limitar as tentativas (constantes, condição composta).
  4. Métodos e validação (jogar, lerInteiro, hasNextInt).
  5. Níveis de dificuldade (enum com atributos).
  6. Jogar de novo e recorde (do-while).

Antes de começar

Este projeto usa o que você viu no projeto da Calculadora (Scanner, métodos, validação) e acrescenta Números Aleatórios e Enums. No seu computador:

$ mkdir -p java/adivinhacao
$ cd java/adivinhacao
Por que as missões usam new Random(7)

Um jogo de sorteio não pode ser conferido automaticamente: cada execução sorteia outro número. Por isso, nas caixas Experimente, o Random recebe uma semente (seed): new Random(7). Com a mesma semente, o Java sorteia sempre a mesma sequência; com a semente 7, o primeiro nextInt(100) + 1 é sempre 37. No seu computador, use new Random(), sem número, para o jogo ser de verdade. A explicação completa está em Números Aleatórios.

Etapa 1 · Sortear e dar um palpite

Primeiro, o mínimo: sortear um número de 1 a 100, ler um palpite e dizer se acertou, se o secreto é maior ou menor. No fim, para conferir, o programa revela o número.

import java.util.Random;
import java.util.Scanner;

public class Adivinhacao {
    public static void main(String[] args) {
        Scanner entrada = new Scanner(System.in);
        Random sorteio = new Random();

        int secreto = sorteio.nextInt(100) + 1;
        System.out.println("Pensei num número de 1 a 100.");
        System.out.print("Palpite: ");
        int palpite = entrada.nextInt();

        if (palpite == secreto) {
            System.out.println("Acertou!");
        } else if (palpite < secreto) {
            System.out.println("É maior que " + palpite + ".");
        } else {
            System.out.println("É menor que " + palpite + ".");
        }
        System.out.println("O número era " + secreto + ".");
    }
}

Etapa 2 · Repetir até acertar

Um palpite só não é jogo. Agora o programa repete a pergunta enquanto o palpite for diferente do secreto, e conta quantas tentativas a pessoa usou.

import java.util.Random;
import java.util.Scanner;

public class Adivinhacao {
    public static void main(String[] args) {
        Scanner entrada = new Scanner(System.in);
        Random sorteio = new Random();

        int secreto = sorteio.nextInt(100) + 1;
        System.out.println("Pensei num número de 1 a 100.");
        int tentativas = 0;
        int palpite = 0;

        while (palpite != secreto) {
            System.out.print("Palpite: ");
            palpite = entrada.nextInt();
            tentativas++;

            if (palpite < secreto) {
                System.out.println("É maior que " + palpite + ".");
            } else if (palpite > secreto) {
                System.out.println("É menor que " + palpite + ".");
            }
        }
        System.out.println("Acertou em " + tentativas + " tentativa(s)!");
    }
}

while (palpite != secreto)
"Enquanto o palpite for diferente do secreto, repita." != é "diferente" (operadores de comparação).
tentativas++;
Soma 1 ao contador a cada volta.

Fica depois do laço: só chega aqui quem acertou.

Etapa 3 · Limitar as tentativas

Sem limite não há como perder, e jogo sem derrota não tem graça. Vamos dar 7 tentativas. Os números 100 e 7 viram constantes: valores com nome, que não mudam.

import java.util.Random;
import java.util.Scanner;

public class Adivinhacao {
    static final int MAXIMO = 100;
    static final int MAX_TENTATIVAS = 7;

    public static void main(String[] args) {
        Scanner entrada = new Scanner(System.in);
        Random sorteio = new Random();

        int secreto = sorteio.nextInt(MAXIMO) + 1;
        System.out.println("Pensei num número de 1 a " + MAXIMO + ". Você tem " + MAX_TENTATIVAS + " tentativas.");
        int tentativas = 0;
        boolean acertou = false;

        while (!acertou && tentativas < MAX_TENTATIVAS) {
            System.out.print("Palpite: ");
            int palpite = entrada.nextInt();
            tentativas++;

            if (palpite == secreto) {
                acertou = true;
            } else if (palpite < secreto) {
                System.out.println("É maior que " + palpite + ".");
            } else {
                System.out.println("É menor que " + palpite + ".");
            }
        }

        if (acertou) {
            System.out.println("Acertou em " + tentativas + " tentativa(s)!");
        } else {
            System.out.println("Acabaram as tentativas. O número era " + secreto + ".");
        }
    }
}
static final int MAX_TENTATIVAS = 7;
final = "final, não muda mais"; static = da classe. Por costume, constantes têm nome em MAIÚSCULAS com _ (veja Constantes). Mudar a dificuldade agora é mudar uma linha só.
boolean acertou = false;
Uma "bandeira" que diz se a pessoa já acertou.
while (!acertou && tentativas < MAX_TENTATIVAS)
Continua enquanto não acertou e ainda tem tentativas. Basta uma das duas ficar falsa para o laço parar.
if (acertou) … else …
Depois do laço, a bandeira diz por que ele parou: vitória ou fim das tentativas.

Etapa 4 · Métodos e validação

Como na calculadora, o main cresceu. Separamos a partida no método jogar e a leitura no método lerInteiro, que recusa o que não for número inteiro. De quebra, o while com bandeira vira um for com return, que fica mais curto:

import java.util.Random;
import java.util.Scanner;

public class Adivinhacao {
    static final int MAXIMO = 100;
    static final int MAX_TENTATIVAS = 7;

    public static void main(String[] args) {
        Scanner entrada = new Scanner(System.in);
        Random sorteio = new Random();
        System.out.println("=== Jogo da Adivinhação ===");
        int resultado = jogar(entrada, sorteio);
        if (resultado == 0) {
            System.out.println("Fica para a próxima!");
        }
    }

    static int jogar(Scanner entrada, Random sorteio) {
        int secreto = sorteio.nextInt(MAXIMO) + 1;
        System.out.println("Pensei num número de 1 a " + MAXIMO + ". Você tem " + MAX_TENTATIVAS + " tentativas.");
        for (int tentativas = 1; tentativas <= MAX_TENTATIVAS; tentativas++) {
            int palpite = lerInteiro(entrada, "Palpite: ");
            if (palpite == secreto) {
                System.out.println("Acertou em " + tentativas + " tentativa(s)!");
                return tentativas;
            } else if (palpite < secreto) {
                System.out.println("É maior que " + palpite + ".");
            } else {
                System.out.println("É menor que " + palpite + ".");
            }
        }
        System.out.println("Acabaram as tentativas. O número era " + secreto + ".");
        return 0;
    }

    static int lerInteiro(Scanner entrada, String pergunta) {
        System.out.print(pergunta);
        while (!entrada.hasNextInt()) {
            System.out.println("\"" + entrada.next() + "\" não é um número inteiro.");
            System.out.print(pergunta);
        }
        return entrada.nextInt();
    }
}

Etapa 5 · Níveis de dificuldade com enum

Agora queremos três níveis: fácil (1 a 10), médio (1 a 50) e difícil (1 a 100), cada um com o seu número de tentativas. Poderíamos usar ints soltos (1, 2, 3) e um monte de if, mas o Java tem algo melhor: o enum (de enumeration, "enumeração", uma lista fechada de opções). Cada nível vira uma constante que carrega os seus próprios dados:

    enum Nivel {
        FACIL(10, 4),
        MEDIO(50, 6),
        DIFICIL(100, 7);

        final int maximo;
        final int tentativas;

        Nivel(int maximo, int tentativas) {
            this.maximo = maximo;
            this.tentativas = tentativas;
        }
    }
enum Nivel { … }
Um tipo novo, Nivel, que só pode ter os valores listados. Ele fica dentro da classe Adivinhacao, como um "enum interno".
FACIL(10, 4)
Uma constante do enum. Os números entre parênteses vão para o construtor: máximo 10, 4 tentativas.
final int maximo;
Atributos: cada nível guarda o seu máximo e as suas tentativas.
Nivel(int maximo, int tentativas)
O construtor, chamado uma vez para cada constante. this.maximo é o atributo; maximo sozinho é o parâmetro (veja this).

import java.util.Random;
import java.util.Scanner;

public class Adivinhacao {

    enum Nivel {
        FACIL(10, 4),
        MEDIO(50, 6),
        DIFICIL(100, 7);

        final int maximo;
        final int tentativas;

        Nivel(int maximo, int tentativas) {
            this.maximo = maximo;
            this.tentativas = tentativas;
        }
    }

    public static void main(String[] args) {
        Scanner entrada = new Scanner(System.in);
        Random sorteio = new Random(7); // semente 7: sorteia sempre o mesmo número
        int recorde = 0; // 0 = ainda não há recorde
        System.out.println("=== Jogo da Adivinhação ===");

        String resposta;
        do {
            Nivel nivel = escolherNivel(entrada);
            int resultado = jogar(entrada, sorteio, nivel);
            if (resultado > 0 && (recorde == 0 || resultado < recorde)) {
                recorde = resultado;
                System.out.println("Novo recorde: " + recorde + " tentativa(s)!");
            }
            System.out.print("Jogar de novo? (s/n): ");
            resposta = entrada.next();
        } while (resposta.equalsIgnoreCase("s"));

        if (recorde == 0) {
            System.out.println("Sem recorde desta vez. Até a próxima!");
        } else {
            System.out.println("Seu recorde: " + recorde + " tentativa(s). Até a próxima!");
        }
    }

    static Nivel escolherNivel(Scanner entrada) {
        Nivel[] niveis = Nivel.values();
        for (int i = 0; i < niveis.length; i++) {
            Nivel n = niveis[i];
            System.out.println((i + 1) + " = " + n + " (1 a " + n.maximo + ", " + n.tentativas + " tentativas)");
        }
        int escolha = lerInteiro(entrada, "Nível: ");
        while (escolha < 1 || escolha > niveis.length) {
            System.out.println("Escolha de 1 a " + niveis.length + ".");
            escolha = lerInteiro(entrada, "Nível: ");
        }
        return niveis[escolha - 1];
    }

    static int jogar(Scanner entrada, Random sorteio, Nivel nivel) {
        int secreto = sorteio.nextInt(nivel.maximo) + 1;
        System.out.println("Pensei num número de 1 a " + nivel.maximo + ". Você tem " + nivel.tentativas + " tentativas.");
        for (int tentativas = 1; tentativas <= nivel.tentativas; tentativas++) {
            int palpite = lerInteiro(entrada, "Palpite: ");
            if (palpite == secreto) {
                System.out.println("Acertou em " + tentativas + " tentativa(s)!");
                return tentativas;
            } else if (palpite < secreto) {
                System.out.println("É maior que " + palpite + ".");
            } else {
                System.out.println("É menor que " + palpite + ".");
            }
            if (Math.abs(palpite - secreto) <= 5) {
                System.out.println("Está quente!");
            }
        }
        System.out.println("Acabaram as tentativas. O número era " + secreto + ".");
        return 0;
    }

    static int lerInteiro(Scanner entrada, String pergunta) {
        System.out.print(pergunta);
        while (!entrada.hasNextInt()) {
            System.out.println("\"" + entrada.next() + "\" não é um número inteiro.");
            System.out.print(pergunta);
        }
        return entrada.nextInt();
    }
}

Resumo

  • nextInt(n) sorteia de 0 a n-1; some 1 para começar em 1. Uma semente fixa repete a sequência.
  • while repete enquanto a condição for verdadeira; um contador com ++ conta as voltas.
  • Constantes static final dão nome aos números mágicos.
  • hasNextInt() valida a entrada; um método que devolve "tentativas ou 0" informa vitória e derrota.
  • Um enum pode ter atributos e construtor; values() lista as constantes.
  • do-while roda pelo menos uma vez: perfeito para "jogar de novo?".
