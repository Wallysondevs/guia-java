Java Métodos de Math

A classe Math é a calculadora científica do Java: potência, raiz, arredondamento, trigonometria e contas protegidas contra overflow. Todos os métodos são static: você escreve Math.sqrt(16), sem criar objeto nenhum, e não precisa de import (ela está em java.lang). A aula com a explicação passo a passo é Math.

Como ler as tabelas
  • Os resultados são reais, do JShell do JDK 25. 1024.0 é um double; 1024 sem ponto é um inteiro.
  • A maioria dos métodos aceita e devolve double. Os que têm versões para int/long (abs, max, min, floorDiv…) devolvem o mesmo tipo que receberam.
  • Números muito pequenos ou grandes aparecem em notação científica: 1.2246467991473532E-16 = 1,22 × 10-16, praticamente zero.

StrictMath: o mesmo resultado em qualquer máquina

StrictMath tem os mesmos métodos que Math, com uma promessa extra: o resultado é idêntico, bit a bit, em qualquer computador, porque segue um algoritmo de referência fixo (a biblioteca fdlibm). O Math pode usar instruções especiais do processador, mais rápidas, que às vezes diferem na última casa decimal (dentro do erro permitido pela documentação).

$ jshell
|  Welcome to JShell -- Version 25.0.4.1
|  For an introduction type: /help intro

jshell> StrictMath.sqrt(2)
$1 ==> 1.4142135623730951

jshell> StrictMath.pow(2, 10)
$2 ==> 1024.0
UseQuando
MathQuase sempre. É o padrão, e o mais rápido.
StrictMathQuando o mesmo cálculo precisa dar o mesmo resultado em máquinas diferentes: simulações científicas reproduzíveis, testes que comparam números com todas as casas.
BigDecimalDinheiro e qualquer conta decimal que precise ser exata (veja BigDecimal e Dinheiro).

A palavra-chave strictfp, que fazia algo parecido para as contas comuns (+, *…), não tem mais efeito desde o Java 17: todas as contas de ponto flutuante já são estritas (veja Palavras-chave).

Armadilhas

Math.round de double devolve long

Este código tem um erro de propósito.

        int arredondado = Math.round(2.5);

$ java Main.java
Main.java:3: error: incompatible types: possible lossy conversion from long to int
        int arredondado = Math.round(2.5);
                                    ^
1 error
error: compilation failed

"Tipos incompatíveis: possível perda na conversão de long para int." Guarde num long, ou converta explicitamente: int arredondado = (int) Math.round(2.5); (veja Conversão de Tipos).

Arredondar para mostrar × arredondar para guardar 
        double raio = 2.5;
        double area = Math.PI * Math.pow(raio, 2);
        System.out.println("Área: " + area);
        System.out.println("Área: " + Math.round(area * 100) / 100.0);
        System.out.printf("Área: %.2f%n", area);

$ java Main.java
Área: 19.634954084936208
Área: 19.63
Área: 19,63                       « printf usa o idioma do sistema: vírgula em pt_BR

Para mostrar, use printf ou String.format (o número guardado continua com todas as casas). O truque do round(x * 100) / 100.0 muda o valor guardado, mas o resultado ainda é um double, com os mesmos pequenos erros de sempre. Para dinheiro, BigDecimal.

Overflow silencioso

Na tabela Contas exatas: 2_000_000_000 + 2_000_000_000 dá -294967296, sem erro nenhum. O resultado não cabe num int e "dá a volta". Quando isso importa (quantidades, contadores, dinheiro em centavos), use Math.addExact/multiplyExact, que lançam ArithmeticException: integer overflow, ou long (veja int, long, short, byte).

Missão: para o círculo de raio 2.5, mostre a área (π r²) e o perímetro (2 π r) arredondados para 2 casas com Math.round(x * 100) / 100.0: Área: 19.63 e Perímetro: 15.71.

public class Main {
    public static void main(String[] args) {
        double raio = 2.5;
        // calcule a área e o perímetro com Math.PI e arredonde para 2 casas
    }
}

public class Main {
    public static void main(String[] args) {
        double raio = 2.5;
        double area = Math.PI * Math.pow(raio, 2);
        double perimetro = 2 * Math.PI * raio;
        System.out.println("Área: " + Math.round(area * 100) / 100.0);
        System.out.println("Perímetro: " + Math.round(perimetro * 100) / 100.0);
    }
}

Exercícios

1. Quanto vale Math.round(-2.5)?

2. Qual a diferença entre -7 / 2 e Math.floorDiv(-7, 2)?

3. Que tipo Math.pow(2, 10) devolve?

Complete para limitar a nota entre 0 e 10 (Java 21+):

int nota = Math.(valor, 0, 10);

Resumo

  • Math é toda static, sem import: Math.metodo(…).
  • Potência e raiz (pow, sqrt) devolvem double; round de double devolve long.
  • floor/ceil/round/rint arredondam de jeitos diferentes; com negativos, confira.
  • floorDiv/floorMod diferem de / e % com negativos; addExact e cia. avisam o overflow.
  • StrictMath: mesmos métodos, resultado idêntico em qualquer máquina.
