Java A Classe Arrays

Na aula Percorrer Arrays você escreveu laços para somar, buscar e inverter. Muitas tarefas com arrays são tão comuns que o Java já traz uma caixa de ferramentas pronta: a classe Arrays. Com uma linha, ela ordena, copia, preenche, compara e procura. Nesta aula você conhece as ferramentas mais usadas, uma de cada vez.

Você vai aprender
  • Como usar a classe Arrays (o import e o "Arrays." na frente).
  • sort: ordenar números e textos (e por que "Érica" vai para o fim).
  • toString e deepToString: mostrar o conteúdo.
  • fill: preencher tudo com um valor.
  • copyOf e copyOfRange: copiar o array inteiro ou um pedaço.
  • equals: comparar o conteúdo (e por que == não serve).
  • binarySearch: a busca rápida, que exige o array ordenado.
  • asList e stream: as pontes para as listas e para as streams.

Os exemplos rodam no terminal da Ana (máquina fictícia notebook, pasta ~/java, JDK 25) com java Main.java.

A ideia antes do código

Você poderia cortar madeira com uma faca de cozinha, mas uma serra faz melhor, mais rápido e sem se machucar. A classe Arrays é a caixa de ferramentas dos arrays: cada ferramenta é um método (uma ação pronta, com nome; os métodos têm uma aula própria em Métodos) que você chama assim:

Arrays
O nome da classe, a "caixa". Com A maiúsculo e s no fim.
.
"De dentro de": pega uma ferramenta da caixa.
sort
O nome do método, a ferramenta: "ordenar".
(notas)
Entre parênteses, o array em que ela vai trabalhar.

A classe mora no pacote java.util (veja Pacotes e import), então todo arquivo que a usa começa com:

import java.util.Arrays;

Sem essa linha, o javac não sabe o que é Arrays e mostra error: cannot find symbol com symbol: variable Arrays (veja o exemplo real em Arrays).

Arrays ≠ array

"Um array" é o seu armário de valores (int[] notas). "Arrays" (com maiúscula) é a classe com as ferramentas. Você nunca cria um Arrays: só usa os métodos dela, passando o seu array.

sort: ordenar

Ordenar do menor para o maior, com uma linha:

import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] notas = {7, 9, 5, 10, 6};
        System.out.println("Antes:  " + Arrays.toString(notas));
        Arrays.sort(notas);
        System.out.println("Depois: " + Arrays.toString(notas));
    }
}

$ java Main.java
Antes:  [7, 9, 5, 10, 6]
Depois: [5, 6, 7, 9, 10]

Repare: o sort não devolve um array novo. Ele arruma o próprio array, como quem arruma os livros na mesma prateleira. A ordem original se perde. Se você precisar dela, faça uma cópia antes (com copyOf, logo abaixo).

Missão: ordene os preços com Arrays.sort e mostre Mais barato: 5, mais caro: 30 usando o primeiro e o último elemento do array ordenado.

import java.util.Arrays;

Ordenar textos: maiúsculas e acentos

Com String, o sort usa a ordem dos códigos dos caracteres (a tabela Unicode, veja char e boolean), e não a ordem do dicionário. Isso dá resultados surpreendentes:

import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        String[] nomes = {"bruno", "Davi", "Érica", "Ana", "carla", "Fábio"};
        Arrays.sort(nomes);
        System.out.println(Arrays.toString(nomes));
        Arrays.sort(nomes, String.CASE_INSENSITIVE_ORDER);
        System.out.println(Arrays.toString(nomes));
    }
}

$ java Main.java
[Ana, Davi, Fábio, bruno, carla, Érica]     « maiúsculas primeiro; Érica no fim
[Ana, bruno, carla, Davi, Fábio, Érica]     « ignorando maiúsculas; Érica continua no fim
  • Na tabela de códigos, todas as maiúsculas (A–Z) vêm antes de todas as minúsculas (a–z). Por isso "Fábio" ficou antes de "bruno".
  • Letras acentuadas têm códigos maiores que qualquer letra sem acento. Por isso "Érica" foi para o fim.
  • String.CASE_INSENSITIVE_ORDER ("ordem que ignora maiúsculas e minúsculas") é um segundo argumento que muda o critério. Resolveu as maiúsculas, mas não os acentos.

Para a ordem do dicionário em português, o Java tem o Collator ("agrupador"), que segue as regras do idioma do computador (na máquina da Ana, português do Brasil):

import java.text.Collator;
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        String[] nomes = {"bruno", "Davi", "Érica", "Ana", "carla", "Fábio"};
        Arrays.sort(nomes, Collator.getInstance());
        System.out.println(Arrays.toString(nomes));
    }
}

$ java Main.java
[Ana, bruno, carla, Davi, Érica, Fábio]

Esses "critérios de ordem" se chamam comparadores e têm uma aula no Nível 3: Comparable e Comparator. Lá você também aprende a ordenar do maior para o menor.

toString e deepToString: mostrar

Você já usou bastante: Arrays.toString(notas) devolve o texto [7, 9, 5, 10, 6]. Ele existe porque System.out.println(notas) mostra só o "crachá" do array ([I@1e9e725a), como explicado em Arrays. Para matrizes (int[][]), use Arrays.deepToString, que mostra todos os níveis (veja Arrays Multidimensionais).

fill: preencher tudo com um valor

Um array novo de int vem cheio de zeros. Se você quer outro valor em todas as posições, o fill ("preencher") faz isso sem laço:

import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] presenca = new int[7];
        Arrays.fill(presenca, 1);
        System.out.println(Arrays.toString(presenca));
        char[] linha = new char[10];
        Arrays.fill(linha, '-');
        System.out.println(linha);
    }
}

$ java Main.java
[1, 1, 1, 1, 1, 1, 1]

copyOf: copiar

Em Arrays você viu que int[] b = a; não copia: cria outro nome para o mesmo array. O copyOf cria um array novo, independente, e ainda deixa escolher o tamanho:

import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] notas = {7, 9, 5, 10, 6};
        int[] copia = Arrays.copyOf(notas, notas.length);
        int[] maior = Arrays.copyOf(notas, 8);
        int[] menor = Arrays.copyOf(notas, 3);
        copia[0] = 0;
        System.out.println("notas: " + Arrays.toString(notas));
        System.out.println("copia: " + Arrays.toString(copia));
        System.out.println("maior: " + Arrays.toString(maior));
        System.out.println("menor: " + Arrays.toString(menor));
    }
}

$ java Main.java
notas: [7, 9, 5, 10, 6]      « o original não mudou
copia: [0, 9, 5, 10, 6]      « só a cópia recebeu o 0
maior: [7, 9, 5, 10, 6, 0, 0, 0]   « as posições novas vêm com o valor padrão
menor: [7, 9, 5]             « o que não coube foi cortado
Arrays.copyOf
A ferramenta "cópia de".
(notas,
O array original.
notas.length)
O tamanho da cópia. Igual ao original: cópia exata. Maior: completa com o valor padrão. Menor: corta o final.

Como um array não muda de tamanho, "aumentar um array" no Java é sempre isto: criar um maior com copyOf e passar a usar o novo. Se você precisa disso o tempo todo, o ArrayList faz sozinho.

Ordenar sem perder a ordem original

Juntando copyOf e sort:

import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] notas = {7, 9, 5, 10, 6};
        int[] ordenadas = Arrays.copyOf(notas, notas.length);
        Arrays.sort(ordenadas);
        System.out.println("Original:  " + Arrays.toString(notas));
        System.out.println("Ordenadas: " + Arrays.toString(ordenadas));
        System.out.println("Menor: " + ordenadas[0] + ", maior: " + ordenadas[ordenadas.length - 1]);
    }
}

$ java Main.java
Original:  [7, 9, 5, 10, 6]
Ordenadas: [5, 6, 7, 9, 10]
Menor: 5, maior: 10

copyOfRange: copiar um pedaço

Para pegar só uma parte, diga onde começa e onde termina:

import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        String[] semana = {"dom", "seg", "ter", "qua", "qui", "sex", "sáb"};
        String[] uteis = Arrays.copyOfRange(semana, 1, 6);
        System.out.println(Arrays.toString(uteis));
    }
}

$ java Main.java
[seg, ter, qua, qui, sex]
Arrays.copyOfRange
"Cópia de um intervalo".
(semana,
O array original.
1,
O índice onde a cópia começa (incluído): "seg".
6)
O índice onde ela para, sem incluir: o 6 é "sáb", que fica de fora.

"Começo incluído, fim excluído" é uma regra que se repete em todo o Java (o substring das Strings é igual). A vantagem: o tamanho do pedaço é sempre fim - início (6 - 1 = 5 dias).

equals: comparar o conteúdo

Dois arrays com os mesmos valores são "iguais"? Depende de como você pergunta:

import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] a = {7, 9, 5};
        int[] b = {7, 9, 5};
        int[] c = a;
        System.out.println("a == b: " + (a == b));
        System.out.println("a == c: " + (a == c));
        System.out.println("Arrays.equals(a, b): " + Arrays.equals(a, b));
        System.out.println("a.equals(b): " + a.equals(b));
    }
}

$ java Main.java
a == b: false                « dois armários diferentes (com o mesmo conteúdo)
a == c: true                 « o mesmo armário, com dois nomes
Arrays.equals(a, b): true    « mesmo tamanho e mesmos valores, na mesma ordem
a.equals(b): false           « parece certo, mas compara como o ==

Com matrizes, o Arrays.equals compara as linhas como "crachás" e dá false mesmo com conteúdo igual; use Arrays.deepEquals, que deu true no laboratório para {{1, 2}, {3, 4}} × {{1, 2}, {3, 4}}. A mesma história do == × equals acontece com as Strings (veja Strings) e com objetos em geral (A Classe Object).

binarySearch: a busca rápida

A busca da aula Percorrer Arrays olha um elemento por vez. Num array ordenado há um jeito muito mais rápido, o mesmo que você usa num dicionário de papel: abre no meio; se a palavra vem antes, descarta a metade de trás; abre no meio do que sobrou… A cada passo, metade do trabalho some. É a busca binária ("binária" porque divide em dois):

import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] notas = {5, 6, 7, 9, 10};
        System.out.println("Posição do 9: " + Arrays.binarySearch(notas, 9));
        System.out.println("Posição do 5: " + Arrays.binarySearch(notas, 5));
        System.out.println("Posição do 8: " + Arrays.binarySearch(notas, 8));
    }
}

$ java Main.java
Posição do 9: 3
Posição do 5: 0
Posição do 8: -4             « negativo = não encontrado
  • Se acha, devolve o índice.
  • Se não acha, devolve um número negativo. Basta testar < 0. (O número exato diz onde o valor deveria entrar: -(posição) - 1. O 8 entraria no índice 3, então -3 - 1 = -4.)
Só funciona com o array ordenado

Num array fora de ordem, o binarySearch não dá erro: dá respostas erradas. Com {7, 9, 5, 10, 6}, no laboratório:

$ java Main.java
Sem ordenar, posição do 9: -4      « o 9 está no índice 1, mas ele "não achou"
Sem ordenar, posição do 5: 2       « este acertou por sorte

Chame Arrays.sort antes, sempre.

asList: o array visto como lista

O Java tem, além dos arrays, as listas (List), que têm muitos métodos prontos, como contains ("contém") e indexOf ("posição de"). O Arrays.asList mostra um array como se fosse uma lista:

import java.util.Arrays;
import java.util.List;

public class Main {
    public static void main(String[] args) {
        String[] frutas = {"maçã", "banana", "uva"};
        List<String> lista = Arrays.asList(frutas);
        System.out.println(lista);
        System.out.println("Tem uva? " + lista.contains("uva"));
        System.out.println("Posição da banana: " + lista.indexOf("banana"));
        lista.set(0, "pera");
        System.out.println(lista);
        System.out.println(Arrays.toString(frutas));
        lista.add("kiwi");
    }
}

$ java Main.java
[maçã, banana, uva]          « uma lista se mostra sozinha, sem toString
Tem uva? true
Posição da banana: 1
[pera, banana, uva]
[pera, banana, uva]          « mudar a lista mudou o array: é o mesmo armário
Exception in thread "main" java.lang.UnsupportedOperationException
	at java.base/java.util.AbstractList.add(AbstractList.java:155)
	at java.base/java.util.AbstractList.add(AbstractList.java:113)
	at Main.main(Main.java:14)

A lista do asList é uma "janela" sobre o array: dá para ler e trocar elementos (set), mas não dá para aumentar ou diminuir, porque o array por trás tem tamanho fixo. O add terminou em UnsupportedOperationException ("operação não suportada"). Para uma lista de verdade, que cresce, faça new ArrayList<>(Arrays.asList(frutas)). As listas são assunto de ArrayList, no Nível 3.

stream: só a ideia

Uma última ferramenta, só para você saber que existe. Arrays.stream(notas) transforma o array numa stream ("fluxo"): uma esteira por onde os valores passam e onde você encaixa operações prontas, como somar ou achar o maior:

import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] notas = {7, 9, 5, 10, 6};
        int soma = Arrays.stream(notas).sum();
        int maior = Arrays.stream(notas).max().getAsInt();
        double media = Arrays.stream(notas).average().getAsDouble();
        System.out.println("Soma: " + soma);
        System.out.println("Maior: " + maior);
        System.out.println("Média: " + media);
    }
}

$ java Main.java
Soma: 37
Maior: 10
Média: 7.4

O mesmo resultado dos laços da aula Percorrer Arrays, em uma linha cada. O getAsInt() e o getAsDouble() existem porque um array vazio não tem maior nem média; isso é explicado em Optional. Streams são uma das partes mais poderosas do Java moderno e têm aula própria: Streams. Por enquanto, os laços que você aprendeu são o caminho certo para entender o que acontece por dentro.

O binarySearch diz que não achou, mas o valor está lá

O array não estava ordenado. Chame Arrays.sort antes. Se a ordem original importa, faça a busca numa cópia ordenada, ou use a busca linear com laço.

Arrays.equals deu false com duas matrizes iguais

Para int[][], use Arrays.deepEquals. O equals só compara o primeiro nível, e lá estão os "crachás" das linhas, que são diferentes.

Resumo

  • java.util.Arrays é a caixa de ferramentas dos arrays; use com import java.util.Arrays; e Arrays.método(array).
  • sort ordena o próprio array (não devolve nada). Textos seguem os códigos dos caracteres: maiúsculas antes, acentuadas no fim; Collator.getInstance() dá a ordem do dicionário.
  • toString/deepToString mostram; fill preenche.
  • copyOf e copyOfRange criam arrays novos (início incluído, fim excluído).
  • Compare conteúdo com Arrays.equals (matrizes: deepEquals), nunca com == ou a.equals(b).
  • binarySearch é rápido, mas só funciona com o array ordenado; negativo = não achou.
  • asList vê o array como lista de tamanho fixo; stream abre a porta para as streams.
